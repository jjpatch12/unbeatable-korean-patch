# UNBEATABLE 한국어패치

UNBEATABLE의 영문 기반 한국어 패치입니다. **1.0 정식 릴리즈**를 제공합니다.

[패치 다운로드](https://github.com/jjpatch12/unbeatable-korean-patch/releases/latest) · [패치 내역](CHANGELOG.md) · [문제 제보](https://github.com/jjpatch12/unbeatable-korean-patch/issues)

## 한국어화 범위

- 대사 **18,234행** 번역 및 문체 검수
- 시스템·UI 테이블 1,978항목 중 **1,894항목 수정**: 메뉴, 설정, 알림, 상호작용, 아케이드, 화자 표시, UI 자막
- 한글 완성형 11,172자를 지원하는 Noto Sans KR 글꼴 연결 및 대사 자동 크기 조정
- 시작 화면의 건강·안전 경고 한국어화
- 슬롯창의 ‘에피소드 선택’ 줄 간격과 위치 조정
- 저널 13쪽, 바 메뉴, 억제기 설계도, 관련 썸네일 2개 한국어화
- 표지판·간판·광고판 텍스처 22개 한국어화
- 설치 전 파일 검사, 자동 백업 및 이전 상태 복구 기능

## 설치 방법

1. 게임을 종료합니다.
2. [릴리즈 페이지](https://github.com/jjpatch12/unbeatable-korean-patch/releases/latest)에서 `UNBEATABLE_한국어패치_1.0.exe`를 다운로드하고 실행합니다.
3. `UNBEATABLE.exe`가 있는 게임 폴더를 선택합니다. `UNBEATABLE_Data` 폴더의 상위 폴더입니다.
4. **게임 폴더 검사**를 누른 뒤 **한국어 패치 적용**을 누릅니다.
5. 게임을 실행하고 언어를 **English**로 설정합니다.

Windows 64비트용 설치 프로그램이며 .NET 런타임이 포함되어 있습니다.

## 백업과 복구

설치 직전 파일은 게임 폴더의 `UNBEATABLE_KoreanPatchBackup`에 자동 백업됩니다.
설치 프로그램에서 **이전 버전 복구**를 누르면 패치 적용 직전 상태로 되돌립니다. 백업 폴더를 보관하세요.
이미 한국어 패치가 적용된 상태에서 다시 설치했다면 복구 후에도 한국어 패치가 남을 수 있습니다.

## 지원 범위와 확인 사항

이 패치는 영문 게임 파일을 기준으로 제작했습니다. 설치기는 대상 파일 18개의 원본 SHA-256 또는 이 패치 적용 후 SHA-256을 확인합니다.
게임 업데이트나 다른 모드로 파일이 달라져 검사를 통과하지 못하면 설치를 중단합니다.

수집 아이템 포스터와 별도 SRT 영상 자막은 이번 버전에 포함되지 않습니다. 고유 브랜드, 약칭, 조작키 등 일부 표기는 원문을 유지합니다.
일부 편집 이미지의 질감·마모·반투명 표현은 원본과 다를 수 있습니다.

## 다운로드 파일 확인

릴리즈에 첨부된 `SHA256.txt`와 다운로드한 EXE의 SHA-256을 비교할 수 있습니다.

```text
3aae0dfbeb8a82a800fe935f3a2ea0475f4ec56838bc895f07f14c789ba379c6  UNBEATABLE_한국어패치_1.0.exe
```

## 문제 제보

오역·누락·글자 잘림은 [Issues](https://github.com/jjpatch12/unbeatable-korean-patch/issues)에 제보해주세요.
장면 또는 메뉴 이름, 문제가 보이는 문구, 스크린샷을 함께 남기면 확인에 도움이 됩니다.
설치 오류는 게임 폴더 검사 결과와 설치 프로그램의 작업 로그를 첨부해주세요. 로그를 공개하기 전에 개인 경로 등 개인정보를 확인하세요.

## 권리 안내

이 프로젝트는 비공식 한국어 패치입니다. 게임과 원본 이미지·로고의 권리는 각 권리자에게 있습니다.
한글 표시는 게임에 포함된 Noto Sans KR 글꼴을 활용합니다.
